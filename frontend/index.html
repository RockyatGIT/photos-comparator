Google Cloud Project & OAuth 2.0 Setup Guide

Follow these 4 simple steps to enable the Google Photos Library API and generate your OAuth client credentials.

  1. 1 Create a Google Cloud Project

    Visit the Google Cloud Console and create a new project (e.g. Photos-Comparator).

  2. 2 Enable Google Photos Picker API (Required)

    Google requires the modern Google Photos Picker API to access your photos:

    • Click here to enable Google Photos Picker API in your project (Click "Enable", takes ~30 seconds to activate).
    • Also ensure "Photos Library API" is enabled.
  3. 3 Configure OAuth Consent Screen

    Go to APIs & Services > OAuth consent screen:

    • Select External User Type and click Create.
    • Add your app name and developer contact email.
    • Under Test users, add the Gmail addresses of BOTH Google accounts you plan to compare.
  4. 4 Create & Save OAuth 2.0 Web Client ID

    Go to APIs & Services > Credentials > Create Credentials > OAuth client ID:

    • Application type: Web application
    • Name: Photos Comparator Local
    • Authorized redirect URIs:
    Configure Credentials Directly Here Checking...

    Paste your generated credentials below. They are saved directly and apply immediately without restarting.
